# companion 包入口补全 —— 改法说明

## 新增/修改文件

| 文件 | 说明 |
|---|---|
| `index.js` | 插件入口：注册 memory_core 工具 + memory-core:snapshot 注入 + webServer API（status/entries/entry） |
| `client.js` | 插件详情页小面板：显示模式/各轨条数/待确认数 + 打开 manage.html 按钮 |
| `manage.html` | 独立窗口记忆管理页：接 API（status/entries/entry），支持增删改/归档/待确认确认/归档移回 |
| `package.json` | 补 dsh.client / exports / peerDeps，版本 0.1.0 |
| `README.md` | 完整说明（安装/配置/轨道/工具/面板/与 evolve 关系） |
| `lib/schema.js` | schemastery config schema（6 个字段） |
| `lib/render.js` | 修正导入：ENTRY_DELIMITER 从 store.js 导入（原从 constants.js 导，不存在） |
| `_dryrun.mjs` | 最小 dryrun：57 项断言 |

## API 端点（/api/memory-core）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/status` | 返回 memoryEnabled/memoryTracks/presetName/memoryDir/tracks |
| GET | `/entries?track=memory` | 返回 entries（正式条目）+ pending（待确认）+ archived（归档） |
| POST | `/entry` | action=add/replace/delete/archive/confirm/reject/promote/removeArchive |

## 已知限制

- webServer API 的 entries 路由硬编码用 `ctx.agent`，在没有 agent 的上下文（如纯 HTTP 调试）会报错
- full 模式的 project/daily 轨在 lite 默认配置下不注入
- manage.html 的「取消编辑」按钮没有单独处理（直接刷新页面即可）
