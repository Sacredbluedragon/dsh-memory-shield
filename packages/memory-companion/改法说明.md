# companion 包入口补全 —— 改法说明

## 新增/修改文件

| 文件 | 说明 |
|---|---|
| `index.js` | 插件入口：注册 memory 工具 + memory:snapshot 注入 + webServer entries API |
| `client.js` | 插件详情页小面板：显示模式/各轨条数/待确认数 + 打开 manage.html 按钮 |
| `package.json` | 补 dsh.client / exports / peerDeps，版本 0.1.0 |
| `README.md` | 完整说明（安装/配置/轨道/工具/面板/与 evolve 关系） |
| `lib/schema.js` | schemastery config schema（6 个字段） |
| `lib/render.js` | 修正导入：ENTRY_DELIMITER 从 store.js 导入（原从 constants.js 导，不存在） |
| `_dryrun.mjs` | 最小 dryrun：11 项断言 |

## 验证

```
node --check index.js client.js lib/schema.js lib/render.js   # 全过
node _dryrun.mjs                                              # 11 pass, 0 fail
```

## 已知限制

- webServer API 的 entries 路由目前硬编码用 `ctx.agent`，在没有 agent 的上下文（如纯 HTTP 调试）会报错
- manage.html 还没接 API（目前是静态页面，需要 DSH 接 fetch）
- full 模式的 project/daily 轨在 lite 默认配置下不注入
